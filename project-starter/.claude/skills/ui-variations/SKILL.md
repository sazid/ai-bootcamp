# UI variations

1. Read `docs/design-system.md`.
2. Build three options that are really different in layout or weight, not only in color.
3. Put them side by side on a temporary `/variations` page.
4. For each option, check text contrast, keyboard focus, and 375px width.
5. Give the pros and cons of each in one or two lines.
6. Do not change the real screen until the user chooses.
