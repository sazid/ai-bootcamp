# Verify UI

1. Run `npm run check`.
2. Open the page in a real browser at 375px and 1280px.
3. Take a screenshot at each size and look at it.
4. Use the keyboard to reach and use each new control.
5. Check the browser console for errors.
6. Report what you saw. If you could not check something, say so.
